# Day 8 - LeetCode String Problems

This folder contains Java solutions for four popular LeetCode String problems.

---

## Problems Covered

### 1. Reverse Words in a String (Medium)
- Reverse the order of words in a string.
- Remove leading, trailing, and extra spaces.
- Uses String split and StringBuilder.

**Time Complexity:** O(n)  
**Space Complexity:** O(n)

---

### 2. Zigzag Conversion (Medium)
- Arrange characters in a zigzag pattern.
- Read row by row to generate the final string.
- Uses multiple StringBuilders to simulate rows.

**Time Complexity:** O(n)  
**Space Complexity:** O(n)

---

### 3. Find the Index of the First Occurrence in a String (Easy)
- Return the first index where `needle` appears in `haystack`.
- Return `-1` if not found.

**Time Complexity:** O(n × m)  
**Space Complexity:** O(1)

Where:
- n = length of haystack
- m = length of needle

---

### 4. Text Justification (Hard)
- Format text so that each line has exactly `maxWidth` characters.
- Distribute spaces evenly between words.
- Left-justify the last line.

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## Learning Outcomes

By solving these problems, you will learn:
- String manipulation
- StringBuilder usage
- Greedy algorithms
- Text formatting techniques
- Pattern simulation
- Two-pointer style traversal
