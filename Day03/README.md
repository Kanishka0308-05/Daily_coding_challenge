# Day 3 - LeetCode Array Problems

Today, I solved four array-based problems that helped me strengthen my understanding of two-pointer techniques, in-place array manipulation, and optimization strategies.

## Problems Solved

### 1. Remove Duplicates from Sorted Array (LeetCode 26)
- Used the two-pointer approach to remove duplicate elements from a sorted array.
- Learned how to modify an array in-place while maintaining O(1) extra space.
- Time Complexity: O(n)
- Space Complexity: O(1)

### 2. Remove Duplicates from Sorted Array II (LeetCode 80)
- Extended the duplicate removal concept by allowing each element to appear at most twice.
- Practiced handling constraints while maintaining efficient performance.
- Time Complexity: O(n)
- Space Complexity: O(1)

### 3. Majority Element (LeetCode 169)
- Implemented the Boyer-Moore Voting Algorithm.
- Learned how to find the majority element using a single pass and constant space.
- Time Complexity: O(n)
- Space Complexity: O(1)

### 4. Rotate Array (LeetCode 189)
- Solved the problem using the array reversal technique.
- Learned how multiple reverse operations can efficiently rotate an array in-place.
- Time Complexity: O(n)
- Space Complexity: O(1)

## Key Concepts Learned
- Two Pointer Technique
- In-Place Array Modification
- Boyer-Moore Voting Algorithm
- Array Reversal Technique
- Time and Space Complexity Optimization
