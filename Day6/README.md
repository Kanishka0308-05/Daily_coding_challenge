# Day 6 - LeetCode Java Solutions

This folder contains Java solutions for the following LeetCode problems:

## Problems Solved

### 1. Roman to Integer (Easy)
- Convert a Roman numeral into its integer value.
- Handles subtraction cases like IV, IX, XL, XC, CD, and CM.
- Time Complexity: O(n)
- Space Complexity: O(1)

### 2. Integer to Roman (Medium)
- Convert an integer into a Roman numeral.
- Uses greedy approach with predefined Roman symbols.
- Time Complexity: O(1)
- Space Complexity: O(1)

### 3. Length of Last Word (Easy)
- Find the length of the last word in a string.
- Ignores trailing spaces.
- Time Complexity: O(n)
- Space Complexity: O(1)

### 4. Longest Common Prefix (Easy)
- Find the longest common prefix among an array of strings.
- Reduces prefix until it matches all strings.
- Time Complexity: O(n × m)
- Space Complexity: O(1)

### 5. Reverse Words in a String (Medium)
- Reverse the order of words in a string.
- Removes extra spaces between words.
- Time Complexity: O(n)
- Space Complexity: O(n)
